# 📖 Glossary

| Term | Meaning |
|---|---|
| Embedding | Numeric vector generated from a detected face |
| Biometric template | Stored representation used to compare a person's face |
| InsightFace | Face analysis library used by the application |
| buffalo_sc | Model pack referenced by the current code |
| ONNX Runtime | Runtime used to execute the model |
| WebRTC | Browser-to-server media transport used for camera frames |
| Redis hash | Key/value structure used for registered embeddings |
| Redis list | Ordered list structure used for attendance event strings |
| Cosine similarity | Similarity measure used to compare embedding vectors |
| FAR | False Acceptance Rate, incorrect acceptance of a non-match |
| FRR | False Rejection Rate, rejection of a genuine match |
| Liveness detection | Mechanism intended to distinguish a live subject from presentation attacks |
| Presentation attack | Spoof attempt using a photo, screen, mask, or other artifact |
| Retention | Period for which personal/biometric data is stored |
| Synthetic data | Artificial test data that does not identify a real person |
| RPO | Recovery Point Objective, acceptable data-loss window |
| RTO | Recovery Time Objective, target restoration time |
