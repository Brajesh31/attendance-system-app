# 📖 Glossary

| Term | Meaning in this project |
|---|---|
| Face detection | Locating a face region in an image frame |
| Face embedding | Numerical vector generated from face analysis |
| InsightFace | Face-analysis toolkit used by the prototype |
| buffalo_sc | Configured InsightFace model pack name |
| ONNX Runtime | Runtime used to execute the configured model |
| Cosine similarity | Measure used to compare two feature vectors |
| FAR | False Acceptance Rate, proportion of impostor comparisons incorrectly accepted |
| FRR | False Rejection Rate, proportion of genuine comparisons incorrectly rejected |
| WebRTC | Browser media transport used by Streamlit camera component |
| Redis hash | Key/value collection used for registered embedding fields |
| Redis list | Ordered collection used for attendance event strings |
| Observation event | A recognition-time sighting, not a validated check-in/out event |
| Liveness | Evidence that the capture is from a live subject rather than a replay or image |
| Retention | Defined period after which data must be deleted |
| Pseudonymization | Replacing direct identifiers with separately controlled identifiers |
| Template | Stored biometric representation used for comparison |
| Unknown | Result when no stored embedding meets the similarity threshold |
