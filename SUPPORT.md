# Support

This is an educational prototype maintained on a best-effort basis.

Read the [installation guide](docs/installation.md), [troubleshooting guide](docs/troubleshooting.md), and [FAQ](docs/faq.md) first. Sanitize logs and never share embeddings, images, attendance records, Redis credentials, or authentication configuration.

Use GitHub issues for reproducible non-security bugs. Use the private process in [SECURITY.md](SECURITY.md) for security or privacy concerns.
