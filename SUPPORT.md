## Include in support requests

- Commit SHA.
- Python and operating system versions.
- Redis version and connection mode, excluding credentials.
- Browser and camera transport information.
- Exact sanitized exception/traceback.
- Steps to reproduce with synthetic data.
- Expected versus observed behavior.

## Never include

Face images, biometric embeddings, real names tied to attendance, raw Redis dumps, passwords, cookie values, API tokens, private config files or private endpoints.

## Where to report

Use GitHub Issues for reproducible defects and documentation improvements. Use private GitHub Security Advisories for security/privacy vulnerabilities.

## Scope

The repository is a prototype and has no hosted service or production support desk.
