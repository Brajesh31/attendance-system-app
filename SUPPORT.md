# 🆘 Support

## Before asking

1. Read [installation](docs/installation.md) and [troubleshooting](docs/troubleshooting.md).
2. Confirm the Python version and active virtual environment.
3. Run the syntax check from [testing strategy](docs/testing-strategy.md).
4. Check Redis connectivity without posting credentials.
5. Verify model files exist and browser camera permission is granted.

## Include in a support request

- Operating system and version.
- Python version and CPU architecture.
- Sanitized package installation output.
- Streamlit and Redis deployment mode.
- Exact page and action that failed.
- Sanitized traceback with all secrets removed.
- Whether the issue reproduces with synthetic data.

## Never include

Face photos, face embeddings, real names, email addresses, attendance logs, Redis passwords, cookie keys, private URLs, or authentication configuration.

## Known limitations

See [known issues](docs/known-issues.md). This is a prototype and no production support SLA is offered.
